# Geareo-STL-JSON-converter

This project takes a given STL and turns it into a Geareo project file.

## Steps to use

1. Run `stl_to_json.py`
2. Click **Browse STL** and pick your file.
3. Set your **Cube Scale Factor** if you want to tweak the block size.
4. Hit **Convert STL**.

The script creates a new folder named after your STL file with everything inside:
* `manifest.json`
* `data.json`
* `thumbnail.png`
